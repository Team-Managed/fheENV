# CLI Commands

## `fheenv login`

Save a wallet private key in a scrypt-derived, AES-256-GCM encrypted local keyfile with permissions
`0600`.

```bash
fheenv login
fheenv login --key 0xABC123...
echo "0x..." | fheenv login
fheenv login --migrate
```

| Flag                     | Description                                                        |
| ------------------------ | ------------------------------------------------------------------ |
| `-k, --key <privateKey>` | 0x-prefixed key. Avoid it in shell history; omit it to read stdin. |
| `--migrate`              | Encrypt an existing legacy plaintext wallet.                       |

Interactive login requests a non-echoing wallet passphrase. Non-interactive use requires
`FHEENV_KEY_PASSPHRASE`. `FHEENV_PRIVATE_KEY` still overrides the keyfile for tightly scoped
automation; external signer custody remains a production-readiness gate.

---

## `fheenv init`

Create an on-chain project and write `.fheenv.json`.

```bash
fheenv init --name "my-app" --pinata-jwt eyJ...
```

| Flag                       | Default              | Description                     |
| -------------------------- | -------------------- | ------------------------------- |
| `-n, --name <name>`        | required             | Project name                    |
| `-r, --registry <address>` | Sepolia registry     | Contract address                |
| `--rpc <url>`              | PublicNode Sepolia   | RPC endpoint                    |
| `--chain-id <id>`          | `11155111`           | Chain ID                        |
| `--pinata-jwt <jwt>`       | `$FHEENV_PINATA_JWT` | Pinata upload credential        |
| `-e, --env <name>`         | `production`         | Default environment             |
| `--analytics`              | disabled             | Opt in to minimal CLI analytics |

---

## `fheenv push`

Encrypt and upload a local environment file.

```bash
fheenv push
fheenv push --env staging --file .env.staging
```

| Flag                | Default      | Description      |
| ------------------- | ------------ | ---------------- |
| `-e, --env <name>`  | `production` | Environment name |
| `-f, --file <path>` | `.env`       | Source file      |

It generates a fresh AES-256-GCM key, encrypts the file locally, uploads the encrypted blob to IPFS,
and writes FHE-encrypted key handles and the CID to the registry.

---

## `fheenv pull`

Decrypt an environment and write it locally.

```bash
fheenv pull
fheenv pull --env staging --output .env.staging.local
```

| Flag                  | Default      | Description         |
| --------------------- | ------------ | ------------------- |
| `-e, --env <name>`    | `production` | Environment to pull |
| `-o, --output <path>` | `.env.local` | Destination file    |

## `fheenv run`

Decrypt secrets and inject them into a child process without writing a file.

```bash
fheenv run -- node server.js
fheenv run --env staging -- npm start
```

## `fheenv team add`

Grant an address access to an environment.

```bash
fheenv team add --member 0xTeammate --env production
```

| Flag                     | Default      | Description    |
| ------------------------ | ------------ | -------------- |
| `-m, --member <address>` | required     | Wallet address |
| `-e, --env <name>`       | `production` | Environment    |

## `fheenv team remove`

Revoke a member and rotate the environment key by default.

```bash
fheenv team remove --member 0xFormer --env production
fheenv team remove --member 0xFormer --env production --file .env
```

<Callout type="warn">
  The contract cannot revoke existing FHE permissions. The CLI therefore rotates immediately after
  revocation. If rotation fails, the command exits non-zero and prints recovery guidance.
  `--no-rotate` leaves the old handles decryptable by the removed wallet.
</Callout>

| Flag                     | Default      | Description                              |
| ------------------------ | ------------ | ---------------------------------------- |
| `-m, --member <address>` | required     | Wallet address to revoke                 |
| `-e, --env <name>`       | `production` | Environment                              |
| `-f, --file <path>`      | `.env`       | Plaintext source used for rotation       |
| `--no-rotate`            | disabled     | Explicitly skip cryptographic revocation |

## `fheenv rotate`

Re-encrypt an environment with a new AES key and re-grant its current active members.

```bash
fheenv rotate
fheenv rotate --env staging --file .env.staging
```

| Flag                | Default      | Description                                 |
| ------------------- | ------------ | ------------------------------------------- |
| `-e, --env <name>`  | `production` | Environment to rotate                       |
| `-f, --file <path>` | `.env`       | Local source file                           |
| `--regrant-only`    | disabled     | Recover member grants without a new version |

## `fheenv export-audit`

Export the local append-only operational log as deterministic CSV.

```bash
fheenv export-audit --output audit.csv
```

This file is local operational evidence. It is not a durable SOC 2 ledger and does not replace
centralized retention or monitoring.

## `fheenv analytics`

CLI analytics are disabled by default.

```bash
fheenv analytics enable
fheenv analytics status
fheenv analytics disable
```

Only a random installation ID, CLI version, operating-system family, command success, and optional
coarse duration bucket may be sent. Wallets, project IDs, environment names, CIDs, transactions,
arguments, paths, errors, and secret-derived values are excluded.

## `fheenv update`

Download and install the latest fheENV release.

```bash
fheenv update
```

## Environment Variables

| Variable                | Description                                               |
| ----------------------- | --------------------------------------------------------- |
| `FHEENV_PRIVATE_KEY`    | Raw wallet key; overrides the local keyfile               |
| `FHEENV_PINATA_JWT`     | Pinata JWT used by `init`                                 |
| `FHEENV_RPC`            | RPC URL override                                          |
| `FHEENV_KEY_PASSPHRASE` | Unlocks the encrypted local wallet                        |
| `FHEENV_ANALYTICS_KEY`  | Optional analytics project key; consent is still required |
